About the IST Chatbot

This chatbot widget provides instant assistance to students, faculty, and staff of Institute of Science and Technology. It uses advanced AI to answer questions about courses, admissions, campus facilities, and other IST-related topics.

Key Features:

  • ✨ Contextual responses based on IST documentation
  • 🔍 Semantic search through IST knowledge base
  • 💬 Natural language conversation interface
  • 📱 Responsive design for all devices
  • 🎯 Source attribution for transparency
  • ⚡ Fast response times

How to Use

Click the chatbot button in the bottom-right corner to start a conversation. You can ask questions like:

  • "What is IST?"
  • "What courses does IST offer?"
  • "How do I apply to IST?"
  • "Tell me about IST facilities"
  • "What are the admission requirements?"

Technical Implementation

The chatbot is powered by Google's Gemini AI model and uses a PostgreSQL database with vector embeddings for semantic search. It's implemented as a FastAPI backend with a JavaScript frontend widget that can be easily integrated into any website.
